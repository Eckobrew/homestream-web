# Android handoff

The maintained Android implementation handoff lives in the backend repository:
https://github.com/Eckobrew/homestream-backend/blob/main/HANDOFF.md

It describes API contract 1.2.0, all-media Discover/Requested, native authenticated music streaming and seeking, Admin authorization, port-3000 pairing, Kids policy, and the Android acceptance checklist. Do not infer API behavior only from web-cookie calls.

Web reference components are DiscoverHub, RequestedPanel, MusicBrowser, MusicPlayer and AdminIntegrations. Generated API snapshot: src/api/. Existing ?tab=requests links map to Discover. No Android source is included or changed in this repository.
